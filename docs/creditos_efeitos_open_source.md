# Créditos dos efeitos open source

O jogo distribui os efeitos abaixo como arquivos locais, sem carregar áudio de serviços de terceiros durante uma partida. Todos estão sob [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). Os créditos são mantidos mesmo quando a licença não exige atribuição.

| Uso no jogo | Arquivos distribuídos | Autoria e referência |
| --- | --- | --- |
| Ambiente diurno | `day-birds.ogg` | isaiah658, [Ambient Bird Sounds no OpenGameArt](https://opengameart.org/content/ambient-bird-sounds) |
| Ambiente noturno | `night-crickets.mp3` | syncopika, [cricket sounds no OpenGameArt](https://opengameart.org/content/cricket-sounds) |
| Fundo noturno | `night-ominous.ogg` | Mix original do projeto, com grilos de syncopika; receita em `scripts/generate_night_soundscape.sh` |
| Interface, passos, aproximação e corte | `kenney/*.ogg` | Kenney Vleugels, [RPG Audio](https://kenney.nl/assets/rpg-audio) |
| Vinheta de vitória | `music/victory.ogg` | Kenney Vleugels, [Music Jingles](https://kenney.nl/assets/music-jingles), faixa `jingles_PIZZA07.ogg` |
| Uivo | `werewolf/howl-long.ogg` | NaturesTemper, [Wolf howl no Freesound](https://freesound.org/people/NaturesTemper/sounds/398430/) |
| Impactos da cena noturna | `werewolf/impact-{1,2,3,4}.ogg` | qubodup, [40 wet towel club/pound/hit/attack sounds no OpenGameArt](https://opengameart.org/content/40-wet-towel-clubpoundhitattack-sounds) |

As cópias de execução de uivo, vitória e impactos receberam conversão para Ogg, normalização e fades. O fundo noturno foi sintetizado pelo projeto, sem geração por IA. Esses tratamentos não alteram a autoria das gravações de origem.

As cópias integrais das licenças Kenney estão em `frontend/public/assets/audio/kenney/license.txt` e `frontend/public/assets/audio/music/license.txt`. Os hashes dos arquivos distribuídos e os downloads de referência estão em [CREDITS.md](../frontend/public/assets/audio/CREDITS.md).
